# Proposte di modifica al paper

Una proposta per file, scritta da una sessione-compito sul proprio ramo (vedi `docs/COLLABORATION.md` §7). Le sessioni-compito non modificano `paper/`: propongono qui; l'autore sceglie; una sola sessione applica al DOCX. Le proposte applicate vanno in `applied/`.

Formato di ogni voce:

```
### <sezione> — "<prime parole esatte del paragrafo nella versione corrente>"
Versione di riferimento: v24i (MD5 docx 1edf5cd9…)

**Testo nuovo**
<paragrafo riscritto per intero>

**Perché**
<una riga>

**Numeri**
<cifra> ← `scripts/python/<script>.py` su `data/<file>` (colonna, anno)
```
